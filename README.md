# Minhas Tarefas

App de tarefas pessoal para iPhone, iPad e Mac. Instale pela tela de início
(Safari → Compartilhar → Adicionar à Tela de Início) e ele roda em tela cheia,
offline, sem custo nenhum.

Documentação completa: [`../README.md`](https://github.com/luizfelipemmonteiro/minhas-tarefas)

- HTML, CSS e JavaScript puro — sem dependências e sem etapa de build.
- Escrita com Apple Pencil, tarefas recorrentes, pastas com tipografia editável.
- Os dados ficam no aparelho. A sincronização (opcional) usa um repositório
  privado do próprio usuário; nada é enviado para terceiros.
